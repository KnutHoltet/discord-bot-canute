# Commands

## Music
| Command | Arguments | Description |
|---------|-----------|-------------|
| `/play` | `playlist` (required Spotify playlist link) | Join your voice channel and append the playlist to the server queue. |
| `/skip` | None | Skip the current song. |
| `/stop` | None | Clear the queue, stop playback and leave voice. |

Music requires the Lavalink setup described in [README.md](README.md).
You must share the bot's voice channel to control active playback.

## Key
